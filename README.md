# Pokedex

A simple and responsive Pokedex web app built with HTML, CSS, and JavaScript using the PokeAPI.

<!-- DE: Eine einfache und responsive Pokedex-Web-App mit HTML, CSS und JavaScript auf Basis der PokeAPI. -->

## Features

<!-- DE: Funktionen -->

- Initial rendering of a Pokemon list (20 to 40 entries)
<!-- DE: Initiales Rendern einer Pokemon-Liste (20 bis 40 Eintraege) -->
- Load More button to fetch additional Pokemon
<!-- DE: Load-More-Button, um weitere Pokemon nachzuladen -->
- Loading feedback while data is being fetched
<!-- DE: Lade-Feedback waehrend Daten geladen werden -->
- Small Pokemon cards with name, type, image, and hover effect
<!-- DE: Kleine Pokemon-Karten mit Name, Typ, Bild und Hover-Effekt -->
- Large overlay view with key stats and card navigation
<!-- DE: Grosse Overlay-Ansicht mit wichtigen Werten und Navigation zwischen Karten -->
- Search with minimum 3 characters before search is allowed
<!-- DE: Suche erst ab mindestens 3 Zeichen aktiv -->
- Caching strategy to avoid duplicate API requests
<!-- DE: Caching-Strategie, damit API-Anfragen nicht doppelt gemacht werden -->
- Lazy loading for additional detail data (for example evolution data)
<!-- DE: Lazy Loading fuer Detaildaten (z. B. Evolutionsdaten) -->

## Tech Stack

<!-- DE: Verwendete Technologien -->

- HTML
- CSS
- JavaScript
- PokeAPI
